# Replay example provenance

`failure.npz` is an actual retained PPO training attempt from local run
`notebook-validation`, seed 101, stage 0. Its outcome is hover_departure.
It was copied unchanged from `0-0-hover_departure-0.npz`.

`reference.npz` is a three-gate flight generated by the deterministic geometric
reference controller, stage 3, reset seed 0. It completed all three ordered gates
in 7.808265403726055 seconds. It is not a learned-policy result.

Both files use the existing `aerorl-notebook-trace-v1` diagnostic format. Build
the reference again with `python -m notebooks.build_browser_examples`; the script
requires the original saved training failure so it cannot silently replace it
with a fabricated example.
